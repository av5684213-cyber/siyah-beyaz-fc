  6. SAFE JSON PARSE — MATCH-TICK ÇÖKME KORUMASI
════════════════════════════════════════════════════════════════════════════════

Dosya: src/app/api/cron/match-tick/route.ts

SORUN:
  - Tüm JSON.parse çağrıları try-catch olmadan çalışıyordu
  - DB'den bozuk JSON gelirse match-tick tamamen çöküyordu
  - Çöken maç 90. dakikaya asla ulaşamıyordu
  - cupSeasonRow.data null ise JSON.parse(null) hatası

ÇÖZÜM:
  - safeJsonParse<T>() yardımcı fonksiyonu eklendi
    - null/undefined → fallback döner
    - object → direkt döner
    - string → JSON.parse dener, hata olursa fallback döner

  Değiştirilen çağrılar:
    a) session.home_players → safeJsonParse<Player[]>(session.home_players, [])
    b) session.away_players → safeJsonParse<Player[]>(session.away_players, [])
    c) session.home_tactic_obj → safeJsonParse<ActiveTactic>(..., {} as ActiveTactic)
    d) session.away_tactic_obj → safeJsonParse<ActiveTactic>(..., {} as ActiveTactic)
    e) session.referee_data → safeJsonParse<Record<string, unknown>>(..., {})
    f) cupSeasonRow.data → safeJsonParse<any>(cupSeasonRow.data, null)
       + null kontrolü: csData null ise kupa güncellemesi atlanır
    g) existingPlayer.match_ratings → safeJsonParse<number[]>(raw, [])
